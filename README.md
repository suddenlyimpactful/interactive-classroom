# interactive-classroom
Interactive Classroom is a collection of educational modules developed for touch-panel display boards in classrooms. What started with a simple, configurable interactive word-sorting exercise has evolved into multiple separate lessons with many more planned.

Visit http://classroom.frycloud.net to view and use the interactive classroom. To host it yourself, download these files and upload the contents of the interactive-classroom folder to your server.

This classroom and these lessons are designed to be used without the need for any database or server-side scripts. They use javascript to run directly in your browser, with sessions saved to the browser file storage.

Word Sort, Matching Pairs, and Label the Diagram allow import/export of configured lessons, which allows teachers to share configurations or save them for future use (in case the browser cache gets cleared or when switching browsers). The other lessons available at this time are easy to configure on the fly, so there is not a need for import/export of settings at this time.

## Lessons and tools

- **Word Sort** – drag words into teacher-defined categories.
- **Place Value Quiz** – name the place of a highlighted digit.
- **Counting Money** – fill a wallet with coins and bills to match an amount.
- **Telling Time** – build a clock face or set its hands to a time.
- **World Explorer** – label the continents and oceans on a world map.
- **Number Line** – mark whole numbers, decimals, and fractions on a line, or name the marked point.
- **Base-Ten Blocks** – build numbers from thousands, hundreds, tens, and ones, or read the blocks.
- **Word Building** – build words from letters, chunks, prefixes, and suffixes in your own word list.
- **Matching Pairs** – connect your own pairs side by side or play them as a memory game.
- **Label the Diagram** – drag names onto a built-in picture or one you upload and mark up yourself.
- **Picker & Timer** – random name picker, random groups, and a large countdown timer.
