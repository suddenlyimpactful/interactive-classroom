# interactive-classroom
Interactive Classroom is a collection of educational modules developed for touch-panel display boards in classrooms. What started with a simple, configurable interactive word-sorting exercise has evolved into multiple separate lessons with many more planned.

Visit http://classroom.frycloud.net to view and use the interactive classroom. To host it yourself, download these files and upload the contents of the interactive-classroom folder to your server.

This classroom and these lessons are designed to be used without the need for any database or server-side scripts. They use javascript to run directly in your browser, with sessions saved to the browser file storage.

The word sort exercise does allow for import/export of configured lessons, which allows teachers to share configurations or save them for future use (in case the browser cache gets cleared or when switching browsers). The other lessons available at this time are easy to configure on the fly, so there is not a need for import/export of settings at this time.
