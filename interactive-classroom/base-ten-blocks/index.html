How is the number built?

Build numbers from thousands, hundreds, tens, and ones, or read the number the blocks show.

Numbers may range from 1 to 9,999. Only the block sizes needed for the largest number appear: up to 99 uses tens and ones, up to 999 adds hundreds, and larger numbers add thousands. Questions may repeat.

Unless the fewest blocks are required, any blocks that add up to the number count as correct, so 12 ones is a fine way to build 12. Up to 20 of each block fit on the mat. Each submitted wrong answer counts as an incorrect attempt.
