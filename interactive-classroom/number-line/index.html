Where does the number belong?

Choose a number line, then mark numbers on it or name the marked point.

A line can have up to 100 spaces between ticks, so a long range needs a larger count-by. Fewer numbers on the line makes the activity harder. Labels are thinned automatically when they would overlap. Questions may repeat. Each submitted wrong answer counts as an incorrect attempt.
