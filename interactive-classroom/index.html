Your work stays with you

Nothing you type into these activities is sent to a server. There are no accounts, and the pages do not collect or upload what you enter.

  • Saved in this browser. Word lists, class names, pictures, settings, and progress are kept in this browser’s storage on this device only. They do not follow you to another computer or another browser.
  • Clearing browser data removes them. If the browser’s site data or cache is cleared, anything saved here is erased.
  • Exported files are yours. Activities with an Export button save a file to this computer. Keep it as a backup, or share it with another teacher, who can load it with Import.
  • Class lists contain student names. Store an exported class list where you keep other rosters.
  • One exception to know about. “Hear the word” in Word Building uses a voice built into the device when there is one. When none is found the option starts switched off, because some browsers would then speak through an online service, which receives the word being read aloud.

Choose an activity, set it up on its first screen, and press Start. Each one works with touch, a mouse, or a keyboard, and has a Full screen button for classroom displays.
